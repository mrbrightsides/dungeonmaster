# 🤝 Contributing to AI Dungeon Master

First off, thank you for considering contributing to AI Dungeon Master! It's people like you that make this infinite world even better.

## 📜 How to Contribute

1.  **Fork** the repository on GitHub.
2.  **Clone** your fork locally.
3.  Create a **new branch** for your feature or bugfix: `git checkout -b feature/amazing-new-spell`.
4.  **Commit** your changes with descriptive messages.
5.  **Push** to your fork: `git push origin feature/amazing-new-spell`.
6.  Open a **Pull Request** against the main repository.

## 🐛 Reporting Bugs
If you find a bug, please open an issue on the [GitHub repository](https://github.com/mrbrightsides/dungeonmaster) with a clear description and steps to reproduce.
